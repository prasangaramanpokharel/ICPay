# Multi-Language Integration

Choose your preferred programming language below to see complete, runnable code examples for scheduling jobs, pausing, resuming, triggering, and inspecting project execution logs.

## 2. Listing Jobs & Querying Execution Logs

Query all scheduled jobs and inspect the execution history without burning any cycles (served via free IC query calls):

<CronCodeTabs
  examples={{
    typescript: `// List all jobs in the project
const jobs = await client.listJobs();
console.log("Active jobs:", jobs);

// Fetch recent execution logs (up to 100 entries, newest first)
const projectLogs = await client.getProjectLogs();

// Fetch logs for a specific job ID
const jobLogs = await client.getJobLogs(job.id);
console.log("Job logs:", jobLogs);`,
    python: `# List all jobs
jobs = client.list_jobs()

# Fetch recent execution logs
project_logs = client.get_project_logs()

# Fetch per-job logs
job_logs = client.get_job_logs(job["id"])
print(f"Total runs: {len(job_logs)}")`,
    go: `// List all jobs
jobs, _ := client.ListJobs()

// Fetch project logs
projectLogs, _ := client.GetProjectLogs()

// Fetch job logs
jobLogs, _ := client.GetJobLogs(job.ID)
fmt.Printf("Total runs: %d\\n", len(jobLogs))`,
    rust: `// List all jobs

## 3. Job Lifecycle (Pause, Resume, Trigger, Delete)

Manage your jobs programmatically:

<CronCodeTabs
  examples={{
    typescript: `// Trigger job immediately out-of-band
await client.trigger({ projectId: 1, jobId: job.id });

// Pause job (releases IC timer slot)
await client.pauseJob(job.id);

// Resume paused job (recomputes next run time)
await client.resumeJob(job.id);

// Permanently delete job and logs
await client.deleteJob(job.id);`,
    python: `# Trigger immediately
client.trigger(project_id=1, job_id=job["id"])

# Pause and Resume
client.pause_job(job["id"])
client.resume_job(job["id"])

# Delete
client.delete_job(job["id"])`,
    go: `// Trigger immediately
client.Trigger(1, job.ID)

// Pause and Resume
client.PauseJob(job.ID)
client.ResumeJob(job.ID)

// Delete
client.DeleteJob(job.ID)`,
    rust: `// Trigger immediately
client.trigger(1, job.id).await?;

// Pause and Resume
client.pause_job(job.id).await?;
client.resume_job(job.id).await?;

// Delete
client.delete_job(job.id).await?;`,
    php: `// Trigger immediately
$client->trigger(1, $job['id']);

// Pause and Resume
$client->pauseJob($job['id']);
$client->resumeJob($job['id']);

// Delete
$client->deleteJob($job['id']);`,
    curl: `# Trigger immediately
curl -X POST "https://w2fxo-5qaaa-aaaan-q6zxq-cai.raw.icp0.io/api/v1/cron/trigger" \\
