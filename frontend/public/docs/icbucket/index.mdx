# ICBucket Documentation

Welcome to the official developer documentation for **ICBucket**, the enterprise decentralized object storage system built natively on the Internet Computer (ICP). ICBucket enables developers to store, retrieve, encrypt, and stream static assets, backups, media, and NFT metadata entirely on-chain — with automatic Edge CDN acceleration via `https://cloud.icpay.app/cloud/`.

## Prerequisites

Before starting, ensure you have:
- An active ICPay account with Internet Identity login.
- An ICBucket created via the [ICPay Bucket Dashboard](/bucket) or via CLI.
- A generated Read/Write API key or your Internet Identity delegation.

## Core Pillars

- **Zero AWS Egress Fees**: Store permanently on-chain without monthly credit card bill surprises.
- **Global Edge CDN**: Files are served through `https://cloud.icpay.app/cloud/{bucketName}/{filePath}` with sub-50ms cache hits.
- **Multi-Language SDKs**: Native clients for TypeScript/Node.js, Python, Rust, and Go.
- **Autonomous & Censorship-Resistant**: Powered by Motoko smart contracts with 100% on-chain integrity verification.
