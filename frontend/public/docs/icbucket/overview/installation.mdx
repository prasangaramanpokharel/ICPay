# Installation

ICBucket offers native SDK libraries across all major programming ecosystems and a single-command developer CLI suite. All source repositories are hosted publicly on GitLab.

## Prerequisites

- For Node.js / TypeScript: Node.js 18 or newer
- For Python: Python 3.9 or newer with `pip`
- For Rust: Rust 1.75 or newer with `cargo`
- For Go: Go 1.21 or newer

## Steps

### Package Managers

Install the client library using your ecosystem's package manager:

```bash
# npm
npm install icpay-bucket

# pnpm
pnpm add icpay-bucket

# yarn
yarn add icpay-bucket

# bun
bun add icpay-bucket

# Python
pip install icpay-bucket

# Rust
cargo add icpay-bucket

# Go
go get gitlab.com/prasangapokharel/icpay-bucket-go
```

### One-Command CLI Developer Suite

For terminal-based file uploads, backup cronjobs, and CI/CD pipelines, install the icBucket CLI tool:

```bash
curl -sSL https://icpay.app/bu/install.sh | bash
```
