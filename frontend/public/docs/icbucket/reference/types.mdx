# Types Reference

This document provides TypeScript type definitions for objects returned by the ICBucket SDK.

## Core Types

### FilePublic

```typescript
export interface FilePublic {
  name: string
  path: string
  sizeBytes: number
  contentType: string
  publicUrl: string
  rawUrl: string
  sha256: string
  createdAt: number
  tags?: string[]
}
```

### BucketStats

```typescript
export interface BucketStats {
  id: string
  name: string
  capacityBytes: number
  usedBytes: number
  fileCount: number
  tier: "starter" | "pro" | "enterprise"
  expiresAt: number
}
```

### FileListPage

```typescript
export interface FileListPage {
  items: FilePublic[]
  page: number
  pageSize: number
  total: number
  totalPages: number
}
```
