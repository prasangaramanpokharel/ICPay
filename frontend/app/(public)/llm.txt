# ICPay

> Fast, secure custodial ICP wallet, decentralized on-chain cloud storage (icBucket), and Web3 developer platform built on the Internet Computer.

ICPay (https://icpay.app) is an Internet Computer (ICP) native platform featuring a custodial multi-token wallet, human-readable username handles, high-throughput on-chain storage with an edge CDN, one-click ICRC token launching, and canister management tooling.

- **Official Domains**: https://icpay.app, https://icpay.cloud, https://icbucket.app, https://onchainstorage.shop

- **Official ICP Index Canister**: `qhbym-qaaaa-aaaaa-aaafq-cai`
- **Authentication**: Internet Identity only (Passkeys, WebAuthn, biometric). Zero passwords, zero seed phrases stored.
- **Custody Model**: Each user possesses an isolated, deterministic subaccount on the backend canister derived from their Internet Identity principal. Only the authenticated principal can execute transfers or withdrawals.

## Core Products & Features
- [Dashboard](https://icpay.app/): Main application dashboard for sending, receiving, and managing ICP and ICRC tokens.
- [Wallet](https://icpay.app/wallet): Multi-token wallet management, address book, subaccounts, and transaction history.
- [icBucket Cloud Storage](https://icpay.app/bucket): Decentralized, encrypted-at-rest file storage and global CDN hosting on the Internet Computer.
- [icBucket Landing Page](https://icpay.app/icbucket): Product overview, pricing tiers, and architecture comparisons with AWS S3.
- [icFalcon Framework](https://icpay.app/icfalcon): High-performance developer CLI and canister operations suite.
- [Token Launcher](https://icpay.app/token/create): Launch custom ICRC-1 / ICRC-2 tokens on the Internet Computer in one click.
- [Canister Manager](https://icpay.app/canister): Deploy, monitor cycles, snapshot, and manage ICP canisters.
- [Topup & Cycles](https://icpay.app/topup): Convert ICP to cycles and top up canisters directly.
- [Community Channels](https://icpay.app/channels): On-chain community channels and token-gated discussions.
- [Charity](https://icpay.app/charity): Transparent, verified on-chain donation campaigns.
