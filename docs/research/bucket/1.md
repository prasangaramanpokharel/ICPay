# icBucket UX Fidelity & Micro-Polish Research

**Document ID:** `docs/research/bucket/1.md`  
**Status:** Completed Architectural & UX Benchmark  
**Core Objective:** Systemic audit, competitive benchmark, and actionable polish roadmap for ICPay Cloud (`icBucket`) without introducing feature bloat.

---

## 1. Executive Summary

ICPay Cloud (`icBucket`) provides an on-chain, S3-compatible decentralized storage platform powered by the Internet Computer. Its underlying infrastructure already combines a Motoko control plane (`icp_wallet_backend`), a high-capacity data plane (`icp_blob_store`), a daily autonomous notifier (`icpay_notifier`), and edge caching (`cdn.icpay.app`).

At this stage of product maturity, **adding massive new features is counter-productive**. Instead, product quality, retention, and developer delight are driven by **micro-interactions, UX fidelity, spatial ergonomics, keyboard fluidity, and visual consistency**. 

This research synthesizes design patterns from industry benchmarks (**Google Drive, Dropbox, AWS S3 Console, Cloudflare R2, MinIO, Supabase Storage, and Uploadthing**) into an engineering blueprint tailored specifically to our current Next.js + Motoko stack.

## 2. Current icBucket Implementation Audit

### 2.1 Existing Capabilities
Our current frontend implementation under `frontend/components/bucket/` is already capable:
* **Dual View Modes:** Both Table (`BucketFilesTable`) and Responsive Card Grid (`BucketFilesGrid`).
* **Folder Hierarchy:** Emulated hierarchical folders via prefix management (`lib/bucket/folderPath.ts`) with breadcrumb navigation.
* **Batch Operations:** Multi-checkbox selection (`BucketSelectBar`), bulk deletion, and single-file move via HTML5 drag-and-drop into folder rows.
* **Upload Management:** Floating bottom-right dock (`BucketUploadDock`) with circular progress, enqueued job tracking, and full-screen drag-and-drop overlay (`BucketUploadControl`).
* **Basic Hotkeys:** Global `useBucketExplorerHotkeys` supporting `Cmd+A` (Select All), `Cmd+D` (Delete), and `Cmd+F` (New Folder).
* **Inspector & Preview:** Drawer-based preview (`BucketFilePreviewPane`) showing image thumbnails, download triggers, CDN links, and metadata.

### 2.2 Friction Points in Current Implementation
1. **Non-Image File Previews are Blank:** In `bucket-file-thumb.tsx` and `bucket-file-preview-pane.tsx`, non-image files (audio, video, PDF, JSON, Motoko/TS code, markdown) only render a generic chip badge. Users are forced to download the file to inspect its content.
2. **Missing Essential Explorer Shortcuts:** Universal file manager hotkeys are missing:
   * `Spacebar` for Quick Look / instant preview.
   * `ArrowUp` / `ArrowDown` for row selection.
   * `Enter` to open a folder or preview a file.
   * `Escape` to dismiss preview or clear selection.
   * `Backspace` / `Delete` to trigger deletion.
   * `?` to open a shortcut cheatsheet.
3. **Upload Dock Telemetry Lacks Velocity & ETA:** The upload dock reports percentage but does not calculate upload speed (e.g., `2.4 MB/s`) or estimated time remaining (ETA), leaving users uncertain during multi-megabyte uploads.
4. **Breadcrumbs Lack Interactive Drop Target:** Users can drag files into folder rows in the table, but dragging a file onto a parent breadcrumb crumb (e.g., dragging back into `Root` or `assets/`) does not move the file up the directory hierarchy.
5. **No Native S3 URI or Curl Snippet Generation:** While CDN and Raw Canister links are displayed, developers frequently need the exact S3 URI (`s3://<bucket-name>/<path>`) or an authenticated `curl` command for CLI scripts.
6. **View Mode & Sort Persistence Lost on Refresh:** Toggling between Table and Grid view or selecting a custom sort order (`size`, `name`, `type`) resets upon page navigation or reload.

## 4. The 8 High-Fidelity Optimization Blueprints

### Optimization 1: Rich In-Drawer File Previews
* **Current Limitation:** Only files with `contentType.startsWith("image/")` render visual previews. Audio, video, text, PDF, and code files show only an icon and a text badge.
* **Enhancement:**
  * **Video (`video/*`):** Render a responsive HTML5 `<video controls preload="metadata" />` player with native seek and fullscreen.
  * **Audio (`audio/*`):** Render a sleek, custom-styled `<audio controls />` player.
  * **Code & Config (`application/json`, `text/plain`, `.mo`, `.ts`, `.md`):** Fetch the first 64 KB of text and render in an embedded read-only `<pre><code>` block with line numbers.
  * **PDF (`application/pdf`):** Embed via `<object data={url} type="application/pdf" />` with a direct "Open in New Tab" fallback.
* **Component Affected:** `frontend/components/bucket/bucket-file-preview-pane.tsx` and `frontend/components/bucket/bucket-file-thumb.tsx`.

### Optimization 2: Comprehensive Keyboard Navigation & Quick Look
* **Current Limitation:** Hotkeys are limited to `Cmd+A`, `Cmd+D`, and `Cmd+F`.
* **Enhancement:**
  * **`Spacebar`:** Opens the preview drawer for the currently focused or selected file (same as macOS Finder & Google Drive). If preview is open, pressing `Spacebar` closes it.
  * **`Escape`:** Dismisses active modal, closes preview drawer, or clears multi-selection.
  * **`Delete` / `Backspace`:** Triggers the delete confirmation dialog if 1+ items are selected.
  * **`Enter`:** If a folder is focused, enters the folder; if a file is focused, opens its preview.
  * **`ArrowDown` / `ArrowUp`:** Move focus highlight to next/previous entry in list view.
  * **`?` or `Cmd+/`:** Opens a minimal hotkey cheatsheet dialog showing all shortcuts.
* **Component Affected:** `frontend/hooks/bucket/useBucketExplorerHotkeys.ts`.

### Optimization 3: Breadcrumb Drop-Target (Upward Moving)
* **Current Limitation:** Moving files is only possible by dragging into a sub-folder row in the table/grid. There is no way to move a file *out* of a folder back to the root or parent.
* **Enhancement:**
  * In `frontend/components/bucket/bucket-detail.tsx`, wrap each `BreadcrumbItem` with HTML5 `onDragOver` and `onDrop` handlers.
  * When a file row is dragged over a parent breadcrumb (e.g. `Root` or a parent folder), highlight the crumb with a subtle ring (`ring-2 ring-primary/80 bg-primary/10`).
  * Dropping on the crumb executes `onMoveFile(sourcePath, targetCrumbPrefix + fileName)`.

### Optimization 4: Upload Velocity & Telemetry
* **Current Limitation:** `BucketUploadDock` shows a circular percentage but provides no feedback on upload speed or time remaining.
* **Enhancement:**
  * Track bytes uploaded over time in `useBucketUpload.ts`.
  * Calculate rolling throughput: `speed = bytesSinceLastInterval / deltaTime`.
  * Display format: `1.8 MB/s · 12s remaining`.
  * Add an individual **"Retry"** button on items that failed due to temporary network timeouts.
* **Component Affected:** `frontend/hooks/bucket/useBucketUpload.ts` and `frontend/components/bucket/bucket-upload-dock.tsx`.

### Optimization 5: S3 URI & Developer Copy Shortcuts
* **Current Limitation:** Preview pane only copies CDN URL and Raw Canister URL.
* **Enhancement:**
  * Add a 1-click **"Copy S3 URI"** button (`s3://${bucketName}/${file.path}`).
  * Add a 1-click **"Copy CLI command"** (`icpay-bucket cp s3://${bucketName}/${file.path} .`).
  * Include a quick-access tab for `@icpay/bucket` TypeScript SDK snippet in the preview pane.
* **Component Affected:** `frontend/components/bucket/bucket-file-preview-pane.tsx`.

### Optimization 6: Persistent Explorer Preferences
* **Current Limitation:** Refreshing resets view mode (`table` vs `grid`), active sort key, and page density.
* **Enhancement:**
  * Save view mode (`table` | `grid`) and sort key (`name` | `size` | `type`) to `localStorage` under `icpay:bucket:viewMode` and `icpay:bucket:sortKey`.
  * Initialize state lazily from `localStorage` without layout shift or hydration mismatch.
* **Component Affected:** `frontend/components/bucket/bucket-files-panel.tsx`.

### Optimization 7: Middle-Truncation for File Names
* **Current Limitation:** Long filenames are truncated at the end (`very-long-file-name-dataset-v...`), which cuts off the critical file extension (e.g. `.png` vs `.csv`).
* **Enhancement:**
  * Implement middle truncation: `very-long-file-name...2026.csv`.
  * Displays the beginning of the name, an ellipsis, and the last 6-8 characters including the extension.
* **Component Affected:** `frontend/components/bucket/bucket-files-table.tsx` and `frontend/components/bucket/bucket-files-grid.tsx`.

### Optimization 8: Enhanced Drag-and-Drop Visual Feedback
* **Current Limitation:** Dragging files over folders triggers a basic class switch, but there is no folder open/lid animation or dropzone ripple.
* **Enhancement:**
  * Apply a smooth spring hover transition to folder icons when dragged over.
  * In grid view, expand folder card scale by `1.03x` with a distinct border pulse during `dragover`.
* **Component Affected:** `frontend/components/bucket/bucket-files-table.tsx` and `frontend/components/bucket/bucket-files-grid.tsx`.

## 6. Conclusion & Recommendation

The fundamental mechanics of `icBucket` (chunked canister storage, billing, CDN routing, and access control) are robust. By investing in these 8 targeted fidelity enhancements, we can elevate `icBucket` from a functional cloud storage dashboard to a consumer-grade, desktop-class file management experience comparable to Apple Finder, Google Drive, and Supabase Storage.
